= Placez un contrôleur en mode service dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si on vous le demande, vous pouvez placer un contrôleur en mode service.

.Avant de commencer
* La baie de stockage doit comporter deux contrôleurs. Le contrôleur que vous ne mettez pas en mode service doit être en ligne (dans un état optimal).
* Assurez-vous qu'aucun volume n'est utilisé ou que vous avez un pilote multipath installé sur tous les hôtes utilisant ces volumes.


[NOTE]
====
Le passage d'un contrôleur en mode service peut réduire considérablement ses performances. Ne passez pas un contrôleur en mode service sans y avoir été invité par le support technique.

====
.Étapes
. Sélectionnez *Hardware*.
. Si le graphique affiche les lecteurs, cliquez sur l’onglet *Controllers & Components*.
+
Le graphique change pour afficher les contrôleurs au lieu des disques.

. Cliquez sur le contrôleur que vous souhaitez placer en mode service.
+
Le menu contextuel du contrôleur apparaît.

. Sélectionnez *Mettre en mode service*, et confirmez que vous souhaitez effectuer l'opération.
