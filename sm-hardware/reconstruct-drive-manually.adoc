= Reconstruire un disque manuellement dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La reconstruction du disque démarre normalement automatiquement après que vous ayez remplacé un disque. Si la reconstruction du disque ne démarre pas automatiquement, vous pouvez lancer la reconstruction manuellement.

[NOTE]
====
Effectuez cette opération uniquement lorsque cela vous est demandé par le support technique ou le Recovery Guru.

====
.Étapes
. Sélectionnez *Hardware*.
. Si le graphique affiche les contrôleurs, cliquez sur l’onglet *Lecteurs*.
+
Le graphique change pour afficher les disques au lieu des contrôleurs.

. Cliquez sur le disque que vous souhaitez reconstruire manuellement.
+
Le menu contextuel du lecteur apparaît.

. Sélectionnez *Reconstruct*, et confirmez que vous souhaitez effectuer l'opération.
