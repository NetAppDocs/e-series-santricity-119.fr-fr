= Afficher les certificats
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez consulter les informations récapitulatives d'un certificat, qui comprennent l'organisation utilisant le certificat, l'autorité qui a délivré le certificat, la période de validité et les empreintes (identifiants uniques).

.Avant de commencer
Vous devez être connecté avec un profil utilisateur disposant des autorisations d'administrateur de sécurité. Sinon, les fonctions de certificat n'apparaissent pas.

.Étapes
. Sélectionnez *Certificate Management*.
. Sélectionnez l'un des onglets suivants :
+
** *Gestion* -- Affiche le certificat du système hébergeant le proxy des services Web. Un certificat de gestion peut être auto-signé ou approuvé par une autorité de certification (CA). Il permet un accès sécurisé à Unified Manager.
** *Trusted* -- Indique les certificats auxquels Unified Manager peut accéder pour les baies de stockage et autres serveurs distants, tels qu’un serveur LDAP. Les certificats peuvent être émis par une autorité de certification (CA) ou être auto-signés.


. Pour afficher plus d'informations sur un certificat, sélectionnez sa ligne, sélectionnez les points de suspension à la fin de la ligne, puis cliquez sur *Afficher* ou *Exporter*.
