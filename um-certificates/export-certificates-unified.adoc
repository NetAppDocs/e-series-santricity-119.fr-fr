= Exporter des certificats dans SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez exporter un certificat pour afficher ses détails complets.

.Avant de commencer
Pour ouvrir le fichier exporté, vous devez disposer d'une application de visualisation de certificats.

.Étapes
. Sélectionnez *Certificate Management*.
. Sélectionnez l'un des onglets suivants :
+
** *Gestion* -- Affiche le certificat du système hébergeant le proxy des services Web. Un certificat de gestion peut être auto-signé ou approuvé par une autorité de certification (CA). Il permet un accès sécurisé à Unified Manager.
** *Trusted* -- Indique les certificats auxquels Unified Manager peut accéder pour les baies de stockage et autres serveurs distants, tels qu’un serveur LDAP. Les certificats peuvent être émis par une autorité de certification (CA) ou être auto-signés.


. Sélectionnez un certificat sur la page, puis cliquez sur les points de suspension à la fin de la ligne.
. Cliquez sur *Exporter*, puis enregistrez le fichier de certificat.
. Ouvrez le fichier dans votre application de visualisation de certificats.
