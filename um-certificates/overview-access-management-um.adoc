La gestion des accès est une méthode de configuration de l'authentification des utilisateurs dans SANtricity Unified Manager.



== Quelles méthodes d'authentification sont disponibles ?

Les méthodes d'authentification suivantes sont disponibles :

* *Rôles utilisateurs locaux* -- L'authentification est gérée par les fonctionnalités RBAC (contrôle d'accès basé sur les rôles). Les rôles utilisateurs locaux comprennent des profils et des rôles prédéfinis avec des autorisations d'accès spécifiques.
* *Services d'annuaire* -- L'authentification est gérée via un serveur LDAP (Lightweight Directory Access Protocol) et un service d'annuaire, tel que Microsoft's Active Directory.
* *SAML* -- L'authentification est gérée par un fournisseur d'identité (IdP) utilisant SAML 2.0.

== Comment configurer la gestion des accès ?

Le logiciel SANtricity est préconfiguré pour utiliser les rôles utilisateurs locaux. Si vous souhaitez utiliser LDAP, vous pouvez le configurer sur la page Gestion des accès.
