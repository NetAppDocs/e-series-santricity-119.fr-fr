= Modifier les serveurs syslog pour les alertes dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier l'adresse du serveur utilisé pour recevoir les alertes syslog.

.Étapes
. Sélectionnez menu : Paramètres[Alertes].
. Sélectionnez l’onglet *Syslog*.
. Dans le tableau, sélectionnez une adresse de serveur syslog, puis cliquez sur l’icône *Modifier* (crayon) à l’extrême droite.
+
La ligne devient un champ modifiable.

. Modifiez l'adresse du serveur et le numéro de port UDP, puis cliquez sur l'icône *Save* (checkmark).


.Résultats
L'adresse du serveur mise à jour apparaît dans le tableau.
