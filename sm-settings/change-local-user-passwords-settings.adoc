= Modifier les paramètres de mot de passe de l'utilisateur local dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez définir la longueur minimale requise pour tous les nouveaux mots de passe ou mots de passe mis à jour des utilisateurs locaux sur la baie de stockage. Vous pouvez également autoriser les utilisateurs locaux à accéder à la baie de stockage sans saisir de mot de passe.

.Avant de commencer
Vous devez être connecté en tant qu'administrateur local, ce qui inclut les autorisations Root admin.

.À propos de cette tâche
Gardez ces consignes à l'esprit lorsque vous définissez la longueur minimale des mots de passe des utilisateurs locaux :

* Les modifications des paramètres n'affecteront pas les mots de passe des utilisateurs locaux existants.
* La longueur minimale requise pour les mots de passe des utilisateurs locaux doit être comprise entre 0 et 30 caractères.
* Tout nouveau mot de passe d'utilisateur local doit respecter ou dépasser la longueur minimale actuellement définie.
* Ne définissez pas de longueur minimale pour le mot de passe si vous souhaitez que les utilisateurs locaux puissent accéder à la storage array sans saisir de mot de passe.


.Étapes
. Sélectionnez le menu : Settings [Gestion des accès].
. Sélectionnez l’onglet *Rôles de l’utilisateur local*.
. Sélectionnez le bouton *Afficher/Modifier les paramètres*.
+
La boîte de dialogue Paramètres du mot de passe de l'utilisateur local s'ouvre.

. Effectuez l'une des opérations suivantes :
+
** Pour permettre aux utilisateurs locaux d'accéder à la baie de stockage _sans_ saisir de mot de passe, décochez la case « Require all local user passwords to be at least ».
** Pour définir une longueur minimale de mot de passe pour tous les mots de passe des utilisateurs locaux, cochez la case « Exiger que tous les mots de passe des utilisateurs locaux aient au moins », puis utilisez le champ de saisie numérique pour définir la longueur minimale requise pour tous les mots de passe des utilisateurs locaux.
+
Tout nouveau mot de passe d'utilisateur local doit respecter ou dépasser le paramètre actuel.



. Cliquez sur *Enregistrer*.
