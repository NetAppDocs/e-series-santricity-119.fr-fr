= Afficher les packages de statistiques iSCSI dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez consulter les données concernant les connexions iSCSI à votre baie de stockage.

.À propos de cette tâche
Le System Manager affiche ces types de statistiques iSCSI. Toutes les statistiques sont en lecture seule et ne peuvent pas être définies.

* *Statistiques MAC Ethernet* -- Fournit des statistiques pour le contrôle d'accès au média (MAC). Le MAC fournit également un mécanisme d'adressage appelé adresse physique ou adresse MAC. L'adresse MAC est une adresse unique attribuée à chaque adaptateur réseau. L'adresse MAC aide à acheminer les paquets de données vers une destination au sein du sous-réseau.
* *Statistiques Ethernet TCP/IP* -- Fournit des statistiques pour le TCP/IP, qui est le Transmission Control Protocol (TCP) et l'Internet Protocol (IP) pour le périphérique iSCSI. Avec TCP, les applications sur des hôtes en réseau peuvent créer des connexions entre elles, sur lesquelles elles peuvent échanger des données en paquets. L'IP est un protocole orienté données qui communique des données à travers un réseau interconnecté à commutation de paquets. Les statistiques IPv4 et les statistiques IPv6 sont affichées séparément.
* *Statistiques de la cible/initiateur local (protocole)* -- Affiche les statistiques de la cible iSCSI, qui fournit un accès au niveau bloc à son support de stockage, et affiche les statistiques iSCSI de la baie de stockage lorsqu'elle est utilisée comme initiateur dans des opérations de mise en miroir asynchrones.
* *Statistiques des états opérationnels de DCBX* -- Affiche les états opérationnels des différentes fonctionnalités de Data Center Bridging Exchange (DCBX).
* *Statistiques TLV LLDP* -- Affiche les statistiques Type Length Value (TLV) du protocole Link Layer Discovery Protocol (LLDP).
* *Statistiques TLV DCBX* -- Affiche les informations permettant d'identifier les ports hôtes de la baie de stockage dans un environnement Data Center Bridging (DCB). Ces informations sont partagées avec les pairs du réseau à des fins d'identification et de capacité.


Vous pouvez consulter chacune de ces statistiques sous forme de statistiques brutes ou de statistiques de référence. Les statistiques brutes correspondent à toutes les statistiques qui ont été collectées depuis le démarrage des contrôleurs. Les statistiques de référence sont des statistiques à un instant donné qui ont été collectées depuis que vous avez défini l'heure de référence.

.Étapes
. Sélectionnez menu : Paramètres [System].
. Sélectionnez *Afficher les packages de statistiques iSCSI*.
. Cliquez sur un onglet pour afficher les différents ensembles de statistiques.
. *Facultatif :* Pour définir la ligne de base, cliquez sur *Définir une nouvelle ligne de base*.
+
L'établissement de la valeur de référence définit un nouveau point de départ pour la collecte des statistiques. La même valeur de référence est utilisée pour toutes les statistiques iSCSI.



Consultez les sections suivantes pour plus d'informations sur les différents types de statistiques.

== Statistiques d'état opérationnel DCBX

Lorsque vous sélectionnez les statistiques d'état opérationnel de Data Center Bridging Exchange (DCBX), les statistiques DCBX apparaissent.

.Statistiques DCBX :
[%collapsible]
====
[cols="25h,~"]
|===
| Statistique | Définition 


 a| 
Port hôte iSCSI
 a| 
Indique l’emplacement du port hôte détecté au format Controller #, Port #.



 a| 
Groupe prioritaire
 a| 
Indique l'état opérationnel de l'application Priority Group (PG). L'état est soit Enabled, soit Disabled.



 a| 
Contrôle de flux basé sur les priorités
 a| 
Indique l'état de fonctionnement de la fonction Priority-based Flow Control (PFC). L'état est soit Enabled, soit Disabled.



 a| 
Fonctionnalité iSCSI
 a| 
Indique l'état de fonctionnement de l'application Internet Small Computer System Interface (iSCSI). L'état est soit Enabled, soit Disabled.



 a| 
Bande passante FCoE
 a| 
Indique l'état de la bande passante Fibre Channel over Ethernet (FCoE). L'état est soit True, soit False.



 a| 
Aucune incohérence de FCoE/FIP Map
 a| 
Indique s'il existe une incompatibilité de mappage entre FCoE et FCoE Initialization Protocol (FIP). La valeur est soit True, soit False.

|===
====

NOTE: Vous pouvez trouver des statistiques supplémentaires sur l'état opérationnel du DCBX dans le fichier de capture d'état.



== Statistiques LLDP TLV

Lorsque vous sélectionnez Link Layer Discovery Protocol (LLDP) Type Length Value (TLV) Statistiques, deux ensembles de statistiques s'affichent : un pour le périphérique local et un pour le périphérique distant. Le périphérique local désigne le contrôleur. Le périphérique distant désigne le périphérique homologue auquel le contrôleur est connecté, généralement un commutateur.

.Statistiques LLDP TLV :
[%collapsible]
====
[cols="25h,~"]
|===
| Statistique | Définition 


 a| 
Port hôte iSCSI
 a| 
Indique l’emplacement du port hôte détecté au format Controller #, Port #.



 a| 
Numéro d'identification du châssis
 a| 
Indique l'identifiant du châssis.



 a| 
Sous-type d'identification du châssis
 a| 
Indique le sous-type d'identifiant du châssis.



 a| 
ID du port
 a| 
Indique l’identifiant du port.



 a| 
Sous-type d'ID de port
 a| 
Indique le sous-type d'identifiant de port.



 a|

 a|

== Statistiques DCBX TLV

Lorsque vous sélectionnez Data Center Bridging Exchange (DCBX) Type Length Value (TLV) Statistics, ces statistiques apparaissent :

* *Statistiques locales* -- Les paramètres DCBX configurés sur le contrôleur à l'usine.
* *Statistiques opérationnelles* -- Les paramètres DCBX qui résultent des négociations DCBX.
* *Statistiques à distance* -- Les paramètres DCBX du périphérique homologue auquel le contrôleur est connecté, généralement un switch.


.Statistiques DCBX TLV :
[%collapsible]
====
[cols="25h,~"]
|===
| Statistique | Définition 


 a| 
Port hôte iSCSI
 a| 
Indique l’emplacement du port hôte détecté au format Controller #, Port #.



 a| 
Mode de contrôle de débit
 a| 
Le mode de contrôle de flux de l'ensemble du port. Les valeurs valides sont Désactivé, Standard, Par priorité ou Indéterminé.



 a| 
Protocole
 a| 
Protocole de communication. Valeurs possibles : FCoE, FIP, iSCSI ou UNKNOWN.



 a| 
Priorité
 a| 
Valeur entière indiquant le numéro de priorité de la communication.



 a| 
Groupe prioritaire
 a| 
Valeur entière représentant le groupe de priorité auquel le protocole a été assigné.



 a| 
Groupe prioritaire % Bandwidth
 a| 
Valeur en pourcentage indiquant la quantité de bande passante allouée au groupe prioritaire.



 a| 
Statut PFC du DCBX
 a| 
État du contrôle de flux basé sur la priorité (PFC) du port spécifique. La valeur est soit activée, soit désactivée.

|===
====

NOTE: Vous pouvez trouver des statistiques TLV supplémentaires pour DCBX dans le fichier de capture d'état.
