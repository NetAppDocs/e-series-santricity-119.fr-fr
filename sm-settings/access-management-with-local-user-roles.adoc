= Configurez la gestion des accès avec les rôles d'utilisateurs locaux dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour la gestion des accès, les administrateurs peuvent utiliser les fonctionnalités RBAC (contrôle d'accès basé sur les rôles) appliquées au niveau de la baie de stockage. Ces fonctionnalités sont appelées « rôles d'utilisateur locaux ».



[[configuration-workflow]]
== Flux de travail de configuration

Les rôles des utilisateurs locaux sont préconfigurés pour la baie de stockage. Pour utiliser les rôles des utilisateurs locaux pour l'authentification, les administrateurs peuvent faire ce qui suit :

. Un administrateur se connecte à System Manager avec un profil utilisateur qui inclut les autorisations Security Admin.
+
[NOTE]
====
L' `admin`utilisateur a un accès complet à toutes les fonctions du système.

====
. Un administrateur examine les profils utilisateur, qui sont prédéfinis et ne peuvent pas être modifiés.
. L'administrateur attribue éventuellement de nouveaux mots de passe à chaque profil utilisateur.
. Les utilisateurs se connectent au système avec leurs identifiants attribués.




[[management]]
== Gestion

Lorsque seuls les rôles d'utilisateur locaux sont utilisés pour l'authentification, les administrateurs peuvent effectuer les tâches de gestion suivantes :

* Changez les mots de passe.
* Définissez une longueur minimale pour les mots de passe.
* Autoriser les utilisateurs à se connecter sans mots de passe.
