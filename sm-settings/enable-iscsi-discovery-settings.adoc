= Activez les paramètres de découverte iSCSI dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez activer les paramètres relatifs à la découverte des périphériques de stockage dans un réseau iSCSI.

Les paramètres de découverte de la cible vous permettent d'enregistrer les informations iSCSI de la baie de stockage à l'aide du protocole Internet Storage Name Service (iSNS), et aussi de déterminer s'il faut autoriser les sessions de découverte sans nom.

.Avant de commencer
Si le serveur iSNS utilise une adresse IP statique, cette adresse doit être disponible pour l'enregistrement iSNS. IPv4 et IPv6 sont pris en charge.

.À propos de cette tâche
Vous pouvez activer les paramètres suivants relatifs à la découverte iSCSI :

* *Activer le serveur iSNS pour enregistrer une cible* -- Lorsque cette option est activée, la baie de stockage enregistre son iSCSI Qualified Name (IQN) et les informations de port depuis le serveur iSNS. Ce paramètre permet la découverte iSNS, afin qu'un initiateur puisse récupérer l'IQN et les informations de port depuis le serveur iSNS.
* *Activer les sessions de découverte anonymes* -- Lorsque les sessions de découverte anonymes sont activées, l'initiateur (hôte iSCSI) n'a pas besoin de fournir l'IQN de la cible (contrôleur) lors de la séquence de connexion pour une connexion de type découverte. Lorsqu'elles sont désactivées, les hôtes doivent fournir l'IQN pour établir une session de découverte avec le contrôleur. Cependant, l'IQN de la cible est toujours requis pour une session normale (portant des E/S). La désactivation de ce paramètre peut empêcher les hôtes iSCSI non autorisés de se connecter au contrôleur en utilisant uniquement son adresse IP.


[NOTE]
====
Les paramètres et fonctions iSCSI ne s'affichent sur la page Paramètres que si votre baie de stockage prend en charge iSCSI.

====
.Étapes
. Sélectionnez menu : Paramètres [System].
. Sous *Paramètres iSCSI*, cliquez sur *Afficher/Modifier les paramètres de découverte de la cible*.
+
La boîte de dialogue Paramètres de découverte de la cible s'affiche. Sous le champ *Activer le serveur iSNS*..., la boîte de dialogue indique si le contrôleur est déjà enregistré.

. Pour enregistrer le contrôleur, sélectionnez *Activer le serveur iSNS pour enregistrer ma cible*, puis sélectionnez l'une des options suivantes :
+
** *Configuration automatique via le serveur DHCP* -- Sélectionnez cette option si vous souhaitez configurer le serveur iSNS à l'aide d'un serveur DHCP (Dynamic Host Configuration Protocol). Notez que si vous utilisez cette option, tous les ports iSCSI du contrôleur doivent également être configurés pour utiliser DHCP. Si nécessaire, mettez à jour les paramètres des ports iSCSI de votre contrôleur pour activer cette option.
+
[NOTE]
====
Pour que le serveur DHCP fournisse l'adresse du serveur iSNS, vous devez configurer le serveur DHCP pour utiliser l'option 43 -- "`Vendor Specific Information.`" Cette option doit contenir l'adresse IPv4 du serveur iSNS dans les octets de données 0xa-0xd (10-13).

====
** *Manually specify static configuration* -- Sélectionnez cette option si vous souhaitez saisir une adresse IP statique pour le serveur iSNS. (Si vous le souhaitez, vous pouvez couper et coller des adresses dans les champs.) Dans le champ, saisissez soit une adresse IPv4, soit une adresse IPv6. Si vous avez configuré les deux, IPv4 est utilisé par défaut. Indiquez également un port d'écoute TCP (utilisez la valeur par défaut 3205 ou saisissez une valeur comprise entre 49152 et 65535).


. Pour permettre à la baie de stockage de participer à des sessions de découverte anonymes, sélectionnez *Enable unnamed discovery sessions*.
+
** Lorsqu'elle est activée, les initiateurs iSCSI ne sont pas tenus de spécifier l'IQN cible pour récupérer les informations du contrôleur.
** Lorsque cette option est désactivée, les sessions de découverte sont empêchées sauf si l'initiateur fournit l'IQN cible. La désactivation des sessions de découverte anonymes offre une sécurité accrue.


. Cliquez sur *Enregistrer*.


.Résultats
Une barre de progression s'affiche pendant que System Manager tente d'enregistrer le contrôleur auprès du serveur iSNS. Ce processus peut prendre jusqu'à cinq minutes.
