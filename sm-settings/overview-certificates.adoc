= Découvrez les certificats dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser SANtricity System Manager pour créer des Certificate Signing Requests (CSRs), importer des certificats et gérer les certificats existants.



[[what-are-certificates]]
== Que sont les certificats?

_Les certificats_ sont des fichiers numériques qui identifient les entités en ligne, telles que les sites web et les serveurs, pour des communications sécurisées sur Internet. Il existe deux types de certificats : un _certificat signé_ est validé par une autorité de certification (CA) et un _certificat auto-signé_ est validé par le propriétaire de l’entité plutôt que par un tiers.

En savoir plus :

* link:how-certificates-work-sam.html["Comment fonctionnent les certificats"]
* link:certificate-terminology.html["Terminologie des certificats"]




[[how-do-i-configure-signed-certificates]]
== Comment configurer des certificats signés ?

Vous pouvez générer une demande de signature depuis System Manager ou en externe à l'aide d'une paire de clés privée et publique. La demande de signature est envoyée à une CA pour générer les fichiers de certificat. Une fois que la CA retourne les fichiers de certificat, vous les importez à l'aide de System Manager.

En savoir plus :

* link:use-ca-signed-certificates-for-controllers.html["Utilisez des certificats signés par une autorité de certification pour les contrôleurs"]
* link:use-ca-signed-certificates-for-authentication-with-a-key-management-server.html["Utilisez des certificats signés par une autorité de certification pour l'authentification avec un serveur de gestion de clés"]
