= Gérer les délais d'expiration de session dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez configurer des délais d'expiration dans SANtricity System Manager, afin que les sessions inactives des utilisateurs soient déconnectées après un délai spécifié.

.À propos de cette tâche
Par défaut, le délai d'expiration de session pour System Manager est de 30 minutes. Vous pouvez ajuster ce délai ou désactiver complètement l'expiration de session.

[NOTE]
====
Si la gestion des accès est configurée à l'aide des fonctionnalités Security Assertion Markup Language (SAML) intégrées dans la baie, une expiration de session peut survenir lorsque la session SSO de l'utilisateur atteint sa limite maximale. Cela peut se produire avant l'expiration de la session System Manager.

====
.Étapes
. Sélectionnez menu : Paramètres [System].
. Dans la section Général, sélectionnez *Activer/Désactiver le Session Timeout*.
+
La boîte de dialogue Activer/Désactiver le délai d'expiration de session s'ouvre.

. Utilisez les commandes de sélection pour augmenter ou diminuer la durée en minutes.
+
Le délai d'expiration minimal que vous pouvez définir pour System Manager est de 15 minutes.

+
[NOTE]
====
Pour désactiver les délais d'expiration de session, décochez la case *Set the length of time...*.

====
. Cliquez sur *Enregistrer*.
