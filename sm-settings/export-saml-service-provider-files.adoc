= Exporter les fichiers du fournisseur de services SAML dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si nécessaire, vous pouvez exporter les métadonnées du Service Provider pour la baie de stockage et réimporter le(s) fichier(s) dans le système Identity Provider (IdP).

.Avant de commencer
* Vous devez être connecté avec un profil utilisateur disposant des autorisations d'administrateur de sécurité. Sinon, les fonctions de gestion des accès ne s'affichent pas.
* SAML est configuré et activé.


.À propos de cette tâche
Dans cette tâche, vous exportez les métadonnées des contrôleurs (un fichier par contrôleur). L'IdP a besoin de ces métadonnées pour établir une relation de confiance avec les contrôleurs et pour traiter les demandes d'authentification. Le fichier contient des informations telles que le nom de domaine du contrôleur ou son adresse IP que l'IdP peut utiliser pour envoyer des demandes.

.Étapes
. Sélectionnez le menu : Settings [Gestion des accès].
. Sélectionnez l’onglet *SAML*.
. Sélectionnez *Export*.
+
La boîte de dialogue Export Service Provider Files s'ouvre.

. Pour chaque contrôleur, cliquez sur *Export* pour enregistrer le fichier de métadonnées sur votre système local.
+
[NOTE]
====
Les champs de nom de domaine de chaque contrôleur sont en lecture seule.

====
+
Notez l'emplacement où le fichier est stocké.

. Depuis le système local, localisez le ou les fichiers de métadonnées du Service Provider que vous avez exportés.
+
Il existe un fichier au format XML pour chaque contrôleur.

. Depuis le serveur IdP, importez le ou les fichiers de métadonnées du Service Provider. Vous pouvez soit importer les fichiers directement, soit saisir manuellement les informations du controller qu'ils contiennent.
. Cliquez sur *Close*.
