= Découvrez la gestion des accès dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La gestion des accès est une méthode permettant d'établir l'authentification des utilisateurs dans SANtricity System Manager.



== Quelles méthodes d'authentification sont disponibles ?

Les méthodes d'authentification comprennent le RBAC (role-based access control), les services d'annuaire et le Security Assertion Markup Language (SAML) :

* *RBAC/Rôles utilisateurs locaux* -- L'authentification est gérée par les fonctionnalités RBAC mises en œuvre dans la baie de stockage. Les rôles utilisateurs locaux comprennent des profils et des rôles prédéfinis avec des autorisations d'accès spécifiques.
* *Services d'annuaire* -- L'authentification est gérée par un serveur LDAP (Lightweight Directory Access Protocol) et des services d'annuaire, tels que Microsoft Active Directory.
* *SAML* -- L'authentification est gérée par un fournisseur d'identité (IdP) utilisant SAML 2.0.

== Comment configurer l'authentification ?

La baie de stockage est préconfigurée pour utiliser les rôles d'utilisateurs locaux, qui sont une implémentation des capacités RBAC. Si vous souhaitez configurer une méthode différente, allez dans menu:Paramètres[Gestion des accès].
