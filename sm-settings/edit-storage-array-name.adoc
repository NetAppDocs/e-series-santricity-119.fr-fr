= Modifier le nom de la baie de stockage dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier le nom de la baie de stockage qui apparaît dans la barre de titre de SANtricity System Manager.

.Étapes
. Sélectionnez menu : Paramètres [System].
. Sous *Général*, recherchez le champ *Nom:*.
+
Si aucun nom de baie de stockage n'a été défini, ce champ affiche "Unknown".

. Cliquez sur l’icône *Modifier* (crayon) à côté du nom de la storage array.
+
Le champ devient modifiable.

. Saisissez un nouveau nom.
+
Un nom peut contenir des lettres, des chiffres et les caractères spéciaux trait de soulignement (_), tiret (-) et dièse (#). Un nom ne peut pas contenir d'espaces. Un nom peut avoir une longueur maximale de 30 caractères. Le nom doit être unique.

. Cliquez sur l’icône *Save* (check mark).
+
[NOTE]
====
Si vous souhaitez fermer le champ modifiable sans apporter de modifications, cliquez sur l’icône *Cancel* (X).

====


.Résultats
Le nouveau nom apparaît dans la barre de titre de SANtricity System Manager.
