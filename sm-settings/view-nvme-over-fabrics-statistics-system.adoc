= Afficher les statistiques NVMe over Fabrics dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez consulter les données concernant les connexions NVMe over Fabrics à votre baie de stockage.

.À propos de cette tâche
Le Gestionnaire système affiche ces types de statistiques NVMe over Fabrics. Toutes les statistiques sont en lecture seule et ne peuvent pas être définies.

* *Statistiques du sous-système NVMe* -- Affiche les statistiques du contrôleur NVMe et de sa file d’attente. Le contrôleur NVMe fournit un chemin d’accès entre un hôte et les espaces de noms de la baie de stockage. Vous pouvez consulter les statistiques du sous-système NVMe pour des éléments tels que les échecs de connexion, les réinitialisations et les arrêts.
* *Statistiques de l'interface RDMA* -- Fournit des statistiques pour tous les ports NVMe over Fabrics sur l'interface RDMA, ce qui inclut les statistiques de performance et les informations sur les erreurs de liaison associées à chaque port du commutateur. Cet onglet s'affiche uniquement lorsque les ports NVMe over Fabrics sont disponibles.


Vous pouvez consulter chacune de ces statistiques sous forme de statistiques brutes ou de statistiques de référence. Les statistiques brutes correspondent à toutes les statistiques qui ont été collectées depuis le démarrage des contrôleurs. Les statistiques de référence sont des statistiques à un instant donné qui ont été collectées depuis que vous avez défini l'heure de référence.

.Étapes
. Sélectionnez menu : Paramètres [System].
. Sélectionnez *View NVMe over Fabrics Statistics*.
. *Facultatif :* Pour définir la ligne de base, cliquez sur *Définir une nouvelle ligne de base*.
+
L'établissement de la ligne de base définit un nouveau point de départ pour la collecte des statistiques. La même ligne de base est utilisée pour toutes les statistiques NVMe.
