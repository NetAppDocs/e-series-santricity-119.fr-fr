= Activez les voyants de localisation des baies de stockage dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour trouver l'emplacement physique d'une baie de stockage dans une armoire, vous pouvez allumer ses voyants de localisation (LED).

.Étapes
. Sélectionnez menu : Paramètres [System].
. Sous *Général*, cliquez sur *Activer les voyants de localisation de la baie de stockage*.
+
La boîte de dialogue « Activer les voyants de localisation de la baie de stockage » s'ouvre et les voyants de localisation de la baie de stockage correspondante s'allument.

. Une fois que vous avez localisé physiquement la baie de stockage, retournez à la boîte de dialogue et sélectionnez *Turn Off*.


.Résultats
Les voyants de localisation s'éteignent et la boîte de dialogue se ferme.
