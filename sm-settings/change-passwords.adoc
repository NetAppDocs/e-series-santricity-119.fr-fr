= Modifier les mots de passe dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier les mots de passe de chaque profil utilisateur dans Access Management.

.Avant de commencer
* Vous devez être connecté en tant qu'administrateur local, ce qui inclut les autorisations Root admin.
* Vous devez connaître le mot de passe de l'administrateur local.


.À propos de cette tâche
Gardez ces directives à l'esprit lors du choix d'un mot de passe :

* Tout nouveau mot de passe d'utilisateur local doit respecter ou dépasser le paramètre actuel pour un mot de passe minimum (dans Afficher/Modifier les paramètres).
* Les mots de passe sont sensibles à la casse.
* Les espaces de fin ne sont pas supprimés des mots de passe lorsqu'ils sont définis. Veillez à inclure les espaces s'ils étaient inclus dans le mot de passe.
* Pour une sécurité accrue, utilisez au moins 15 caractères alphanumériques et changez fréquemment le mot de passe.


[NOTE]
====
Modifier le mot de passe dans le Gestionnaire système le modifie également dans la ligne de commandes (CLI). De plus, toute modification du mot de passe entraîne la fermeture de la session utilisateur.

====
.Étapes
. Sélectionnez le menu : Settings [Gestion des accès].
. Sélectionnez l’onglet *Rôles de l’utilisateur local*.
. Sélectionnez un utilisateur dans le tableau.
+
Le bouton Changer le mot de passe devient disponible.

. Sélectionnez *Change Password*.
+
La boîte de dialogue Changer le mot de passe s'ouvre.

. Si aucune longueur minimale de mot de passe n'est définie pour les mots de passe des utilisateurs locaux, vous pouvez cocher la case pour exiger que l'utilisateur sélectionné saisisse un mot de passe pour accéder à la baie de stockage, puis vous pouvez saisir le nouveau mot de passe pour l'utilisateur sélectionné.
. Saisissez votre mot de passe d'administrateur local, puis cliquez sur *Change*.


.Résultats
Si l'utilisateur est actuellement connecté, la modification du mot de passe entraîne la fin de sa session active.
