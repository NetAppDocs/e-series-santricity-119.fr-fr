= Ajouter des communautés pour les traps SNMPv2c dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez ajouter jusqu'à 256 noms de communauté pour les traps SNMPv2c.

.Étapes
. Sélectionnez menu : Paramètres[Alertes].
. Sélectionnez l’onglet *SNMP*.
+
Les destinations des pièges et les noms des communautés apparaissent dans le tableau.

. Sélectionnez *Configure Communities*.
+
La boîte de dialogue Configure Communities s'ouvre.

. Sélectionnez *Add another community*.
. Saisissez le nouveau nom de la communauté, puis cliquez sur *Save*.


.Résultats
Le nouveau nom de la communauté apparaît dans l'onglet SNMP de la page Alertes.
