= Supprimer le serveur d'annuaire dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour rompre la connexion entre un serveur d'annuaire et la baie de stockage, vous pouvez supprimer les informations du serveur depuis la page Access Management. Vous pourriez vouloir effectuer cette tâche si vous avez configuré un nouveau serveur, puis souhaitez supprimer l'ancien.

.Avant de commencer
Vous devez être connecté avec un profil utilisateur disposant des autorisations d'administrateur de sécurité. Sinon, les fonctions de gestion des accès ne s'affichent pas.

.À propos de cette tâche
Après avoir terminé cette tâche, toutes les sessions utilisateur actives sont terminées. Seule votre session utilisateur actuelle est conservée.

.Étapes
. Sélectionnez le menu : Settings [Gestion des accès].
. Sélectionnez l’onglet *Services d’annuaire*.
. Dans la liste, sélectionnez le serveur d'annuaire que vous souhaitez supprimer.
. Cliquez sur *Remove*.
+
La boîte de dialogue Supprimer Directory Server s'ouvre.

. Tapez  `remove` dans le champ, puis cliquez sur *Supprimer*.
+
Les paramètres de configuration du serveur d'annuaire, les paramètres de privilèges et les mappages de rôles sont supprimés. Les utilisateurs ne peuvent plus se connecter avec des identifiants provenant de ce serveur.
