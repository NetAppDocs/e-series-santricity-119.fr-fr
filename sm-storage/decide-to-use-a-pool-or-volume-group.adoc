= Découvrez les pools et les groupes de volumes dans le logiciel SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez créer des volumes à l'aide d'un pool ou d'un groupe de volumes. Le choix optimal dépend principalement des exigences clés en matière de stockage, telles que la charge d'E/S prévue, les exigences de performance et les exigences de protection des données.



== Raisons de choisir un pool ou un groupe de volumes

*Choisissez un pool*

* Si vous avez besoin de reconstructions de disques plus rapides et d'une administration du stockage simplifiée, si vous avez besoin de volumes fins et/ou si votre charge de travail est très aléatoire.
* Si vous souhaitez répartir les données de chaque volume de manière aléatoire sur un ensemble de disques qui composent le pool.
+
Vous ne pouvez pas définir ni modifier le niveau RAID des pools ou des volumes dans les pools. Les pools utilisent le niveau RAID 6.



*Choisissez un groupe de volumes*

* Si vous avez besoin d'une bande passante système maximale, de la possibilité de régler les paramètres de stockage et d'une charge de travail hautement séquentielle.
* Si vous souhaitez répartir les données sur les disques en fonction d'un niveau RAID. Vous pouvez spécifier le niveau RAID lors de la création du groupe de volumes.
* Si vous souhaitez écrire les données de chaque volume de manière séquentielle sur l'ensemble des disques qui composent le groupe de volumes.


[NOTE]
====
Étant donné que les pools peuvent coexister avec les groupes de volumes, une baie de stockage peut contenir à la fois des pools et des groupes de volumes.

====
