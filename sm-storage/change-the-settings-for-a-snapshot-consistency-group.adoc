= Modifiez les paramètres d'un groupe de cohérence de snapshot dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Modifiez les paramètres d'un groupe de cohérence d'instantanés lorsque vous souhaitez changer son nom, ses paramètres de suppression automatique ou le nombre maximal d'images d'instantanés autorisées.

.Étapes
. Sélectionnez le menu : Storage[Snapshots].
. Cliquez sur l'onglet *Snapshot Consistency Groups*.
. Sélectionnez le groupe de cohérence de snapshot que vous souhaitez modifier, puis cliquez sur *Afficher/Modifier les paramètres*.
+
La boîte de dialogue « Paramètres du groupe de cohérence des instantanés » s'affiche.

. Modifiez les paramètres du groupe de cohérence de l'instantané selon vos besoins.
+
.Détails du champ
[%collapsible]
====
[cols="25h,~"]
|===
| Paramètre | Description 


 a| 
*Paramètres du groupe de cohérence des instantanés*



 a| 
Nom
 a| 
Vous pouvez modifier le nom du groupe de cohérence de l'instantané.



 a| 
Suppression automatique
 a| 
Laissez la case à cocher cochée si vous souhaitez que les images instantanées soient automatiquement supprimées après la limite spécifiée ; utilisez le champ numérique pour modifier la limite. Si vous décochez cette case à cocher, la création d'images instantanées s'arrête après 32 images.



 a| 
Limite d'image instantanée
 a| 
Vous pouvez modifier le nombre maximal d'images instantanées autorisées pour un groupe d'instantanés.



 a| 
Calendrier des snapshots
 a| 
Ce champ indique si une planification est associée au groupe de cohérence de snapshot.



 a| 
*Objets associés*



 a| 
Volumes membres
 a| 
Vous pouvez consulter la quantité de volumes membres associés au groupe de cohérence de l'instantané.

|===
====
. Cliquez sur *Enregistrer*.
