= Modifiez les identifiants de port hôte pour un hôte dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Modifiez les identifiants de port hôte lorsque vous souhaitez changer l'étiquette utilisateur sur un identifiant de port hôte, ajouter un nouvel identifiant de port hôte à l'hôte ou supprimer un identifiant de port hôte de l'hôte.

.À propos de cette tâche
Lors de la modification des identifiants de port hôte, gardez à l'esprit les consignes suivantes :

* *Ajouter* -- Lorsque vous ajoutez un port hôte, vous associez l'identifiant du port hôte à l'hôte que vous avez créé pour vous connecter à votre baie de stockage. Vous pouvez saisir manuellement les informations de port à l'aide d'un utilitaire d'adaptateur de bus hôte (HBA).
* *Modifier* -- Vous pouvez modifier les ports hôtes pour déplacer (associer) un port hôte à un autre hôte. Vous avez peut-être déplacé l'adaptateur de bus hôte ou l'initiateur iSCSI vers un autre hôte, vous devez donc déplacer (associer) le port hôte vers le nouvel hôte.
* *Supprimer* -- Vous pouvez supprimer les ports hôtes pour retirer (dissocier) les ports hôtes d'un hôte.


.Étapes
. Sélectionnez le menu : Storage[Hosts].
. Sélectionnez l'hôte auquel les ports seront associés, puis cliquez sur *Afficher/Modifier les paramètres*.
+
Si vous souhaitez ajouter des ports à un hôte dans un cluster d'hôtes, développez le cluster d'hôtes et sélectionnez l'hôte souhaité. Vous ne pouvez pas ajouter de ports au niveau du cluster d'hôtes.

+
Une boîte de dialogue s'affiche, affichant les paramètres d'hôte actuels.

. Cliquez sur l'onglet *Ports hôtes*.
+
La boîte de dialogue affiche les identifiants de port d'hôte actuels.

. Modifiez les paramètres d'identification du port hôte selon vos besoins.
+
[cols="25h,~"]
|===
| Paramètre | Description 


 a| 
Port hôte
 a| 
Vous pouvez choisir l'une des options suivantes :

** *Ajouter* -- Utilisez Ajouter pour associer un nouvel identifiant de port hôte à l'hôte. La longueur du nom de l'identifiant de port hôte est déterminée par la technologie d'interface d'hôte. Les noms d'identifiants de port hôte Fibre Channel et Infiniband doivent comporter 16 caractères. Les noms d'identifiants de port hôte iSCSI ont un maximum de 223 caractères. Le port doit être unique. Un numéro de port déjà configuré n'est pas autorisé.
** *Supprimer* : utilisez Supprimer pour retirer (dissocier) un identifiant de port hôte. L’option Supprimer ne supprime pas physiquement le port hôte. Cette option supprime l’association entre le port hôte et l’hôte. À moins de supprimer l’adaptateur de bus hôte ou l’initiateur iSCSI, le port hôte reste reconnu par le contrôleur.
+
[NOTE]
====
Si vous supprimez un identifiant de port hôte, celui-ci n'est plus associé à cet hôte. De plus, l'hôte perd l'accès à tous les volumes qui lui sont attribués via cet identifiant de port hôte.

====




 a| 
Étiquette
 a| 
Pour modifier le nom du port, cliquez sur l'icône *Modifier* (crayon). Le nom du port doit être unique. Un nom de port déjà configuré n'est pas autorisé.



 a| 
Secret CHAP
 a| 
Cette option s'affiche uniquement pour les hôtes iSCSI. Vous pouvez définir ou modifier le secret CHAP des initiateurs (hôtes iSCSI).

System Manager utilise le protocole Challenge Handshake Authentication Protocol (CHAP), qui valide l'identité des cibles et des initiateurs lors de la connexion initiale. L'authentification repose sur une clé de sécurité partagée appelée secret CHAP.

|===
. Cliquez sur *Enregistrer*.
