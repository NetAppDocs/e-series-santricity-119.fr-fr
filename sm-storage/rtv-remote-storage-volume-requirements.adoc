= Découvrez les exigences relatives aux volumes de stockage distant dans le logiciel SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Les volumes utilisés pour les importations doivent satisfaire aux exigences de taille, de statut et d'autres critères.



== volume de stockage distant

Le volume source d'une importation est appelé « remote storage volume ». Ce volume doit répondre aux critères suivants :

* Ne peut pas faire partie d'une autre importation
* Doit avoir un statut en ligne


Une fois l'importation lancée, le micrologiciel du contrôleur crée en arrière-plan un volume de stockage distant. En raison de ce processus en arrière-plan, le volume de stockage distant n'est pas gérable dans System Manager et ne peut être utilisé que pour l'opération d'importation.

Une fois créé, le volume de stockage distant est traité comme n'importe quel autre volume standard du système E-Series, à quelques exceptions près :

* Peut être utilisé comme proxy pour le périphérique de stockage distant.
* Ne peut pas être utilisé comme candidats pour d'autres copies de volume ou snapshots.
* Impossible de modifier le paramètre Data Assurance pendant l'importation.
* Impossible de les associer à des hôtes, car ils sont strictement réservés à l'opération d'importation.


Chaque volume de stockage distant est associé à un seul objet de stockage distant ; toutefois, un objet de stockage distant peut être associé à plusieurs volumes de stockage distants. Le volume de stockage distant est identifié de manière unique à l'aide d'une combinaison des éléments suivants :

* identificateur d'objet de stockage distant
* Numéro LUN du périphérique de stockage distant




== Candidats au volume cible

Le volume cible est le volume de destination sur le système de stockage E-Series local. Le volume de destination doit répondre aux critères suivants :

* Doit être un volume RAID/DDP.
* Doit avoir une capacité égale ou supérieure à celle du volume de stockage distant.
* Doit avoir une taille de bloc identique à celle du volume de stockage distant.
* Doit avoir un état valide (optimal).
* Ne peut avoir aucune des relations suivantes : copie de volume, copies instantanées, mise en miroir asynchrone ou synchrone.
* Ne peut faire l'objet d'aucune opération de reconfiguration : Dynamic Volume Expansion, Dynamic Capacity Expansion, Dynamic Segment Size, Dynamic RAID Migration, Dynamic Capacity Reduction ou Defragmentation.
* Impossible d'associer à un hôte avant le début de l'importation (cependant, il peut être associé après la fin de l'importation).
* Impossible d'avoir Flash Read Cached (FRC) activé.


System Manager vérifie automatiquement ces exigences dans le cadre de l'assistant d'importation de stockage distant. Seuls les volumes répondant à toutes les exigences sont proposés pour la sélection du volume de destination.
