= Découvrez la terminologie hôte dans le logiciel SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Découvrez comment les termes relatifs à l'hôte s'appliquent à votre baie de stockage.

[cols="25h,~"]
|===
| Composant | Définition 


 a| 
Hôte
 a| 
Un hôte est un serveur qui envoie des E/S à un volume sur une baie de stockage.



 a| 
Nom d'hôte
 a| 
Le nom de l'hôte doit correspondre au nom système de l'hôte.



 a| 
Cluster hôte
 a| 
Un cluster d'hôtes est un groupe d'hôtes. Vous créez un cluster d'hôtes pour faciliter l'attribution des mêmes volumes à plusieurs hôtes.



 a| 
Protocole d'interface d'hôte
 a| 
Un protocole d'interface d'hôte est la connexion (telle que Fibre Channel, iSCSI, etc.) entre les contrôleurs et les hôtes.



 a| 
Carte HBA ou carte d'interface réseau (NIC)
 a| 
Un adaptateur de bus hôte (HBA) est une carte qui réside dans un hôte et contient un ou plusieurs ports hôtes.



 a| 
Port hôte
 a| 
Un port hôte est un port sur un adaptateur de bus hôte (HBA) qui assure la connexion physique à un contrôleur et est utilisé pour les opérations d'E/S.



 a| 
Identifiant du port hôte
 a| 
Un identifiant de port hôte est un nom unique au niveau mondial associé à chaque port hôte sur un adaptateur de bus hôte (HBA).

* Les identificateurs de port hôte Internet Small Computer System Interface (iSCSI) doivent comporter entre 1 et 233 caractères. Les identificateurs de port hôte iSCSI s'affichent au format IQN standard (par exemple,  `iqn.xxx.com.xxx:8b3ad`).
* Les identifiants de ports hôtes non iSCSI, tels que Fibre Channel et Serial Attached SCSI (SAS), s'affichent sous forme de groupes de deux caractères séparés par des deux-points (par exemple,  `xx:yy:zz`). Les identifiants de ports hôtes Fibre Channel doivent comporter 16 caractères.




 a| 
Type de système d'exploitation hôte
 a| 
Le type de système d'exploitation hôte est un paramètre de configuration qui définit la manière dont les contrôleurs de la baie de stockage réagissent aux E/S en fonction du système d'exploitation (ou de sa variante) de l'hôte. Ceci est aussi parfois appelé _type d'hôte_ pour faire court.



 a| 
port hôte du contrôleur
 a| 
Un port hôte de contrôleur est un port du contrôleur qui assure la connexion physique à un hôte et est utilisé pour les opérations d'E/S.



 a| 
LUN
 a| 
Un numéro d'unité logique (LUN) est le numéro attribué à l'espace d'adressage qu'un hôte utilise pour accéder à un volume. Le volume est présenté à l'hôte comme une capacité sous la forme d'un LUN.

Chaque hôte possède son propre espace d'adressage LUN. Par conséquent, le même LUN peut être utilisé par différents hôtes pour accéder à des volumes différents.

|===
