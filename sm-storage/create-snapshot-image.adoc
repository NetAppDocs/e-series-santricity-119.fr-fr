= Créer une image instantanée dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez créer manuellement une image instantanée à partir d'un volume de base ou d'un groupe de cohérence de snapshots. Ceci est également appelé un _instant snapshot_ ou une _instant image_.

.Avant de commencer
* Le volume de base doit être optimal.
* Le lecteur doit être optimal.
* Le groupe d'instantanés ne peut pas être désigné comme « reserved. »
* Le volume de capacité réservée doit avoir les mêmes paramètres de Data Assurance (DA) que le volume de base associé pour le groupe d'instantanés.


.Étapes
. Effectuez l'une des actions suivantes pour créer une image instantanée :
+
** Sélectionnez le menu : Storage[Volumes]. Sélectionnez l’objet (base volume ou snapshot consistency group), puis sélectionnez le menu : Copy Services[Create instant snapshot].
** Sélectionnez menu : Storage[Snapshots]. Sélectionnez l’onglet *Snapshot Images*, puis sélectionnez menu : Create[Instant snapshot].
+
La boîte de dialogue « Créer une image instantanée » s’affiche. Sélectionnez l’objet (volume de base ou groupe de cohérence d’instantanés), puis cliquez sur *Suivant*. Si une image instantanée précédente a été créée pour le volume ou le groupe de cohérence d’instantanés, alors le système crée l’instantané immédiatement. Sinon, s’il s’agit de la première création d’une image instantanée pour le volume ou le groupe de cohérence d’instantanés, la boîte de dialogue « Confirmer la création de l’image instantanée » s’affiche.



. Cliquez sur *Créer* pour accepter la notification indiquant qu'une capacité réservée est nécessaire et pour passer à l'étape Reserve Capacity.
+
La boîte de dialogue « Capacité de réserve » apparaît.

. Utilisez le champ de saisie pour ajuster le pourcentage de capacité, puis cliquez sur *Next* pour accepter le volume candidat mis en évidence dans le tableau.
+
La boîte de dialogue Modifier les paramètres apparaît.

. Sélectionnez les paramètres de l'image instantanée comme il convient, puis confirmez que vous souhaitez effectuer l'opération.
+
.Détails du champ
[%collapsible]
====
[cols="25h,~"]
|===
| Paramètre | Description 


 a| 
*Paramètres de l'image Snapshot*



 a| 
Limite d'image instantanée
 a| 
Laissez la case à cocher cochée si vous souhaitez que les images instantanées soient automatiquement supprimées après la limite spécifiée ; utilisez le champ numérique pour modifier la limite. Si vous décochez cette case à cocher, la création d'images instantanées s'arrête après 32 images.



 a| 
*Paramètres de capacité réservée*



 a| 
Alertez-moi quand...
 a| 
Utilisez la case de sélection pour ajuster le point de pourcentage auquel le système envoie une notification d'alerte lorsque la capacité réservée pour un groupe d'instantanés est presque pleine.

Lorsque la capacité réservée pour le groupe d'instantanés dépasse le seuil spécifié, utilisez l'avis préalable pour augmenter la capacité réservée ou supprimer les objets inutiles avant que l'espace restant ne soit épuisé.



 a| 
Politique de capacité entièrement réservée
 a| 
Choisissez l'une des politiques suivantes :

** *Suppression de l'image instantanée la plus ancienne* -- Le système supprime automatiquement l'image instantanée la plus ancienne du groupe d'instantanés, ce qui libère la capacité réservée à l'image instantanée pour une réutilisation au sein du groupe.
** *Rejeter les écritures sur le volume de base* -- Lorsque la capacité réservée atteint son pourcentage maximal défini, le système rejette toute requête d'écriture d'I/O sur le volume de base qui a déclenché l'accès à la capacité réservée.


|===
====


.Résultats
* System Manager affiche la nouvelle image instantanée dans le tableau Images instantanées. Le tableau répertorie la nouvelle image par horodatage et par volume de base associé ou groupe de cohérence de snapshot.
* La création de l'instantané peut rester en attente en raison des conditions suivantes :
+
** Le volume de base qui contient cette image instantanée est membre d'un groupe miroir asynchrone.
** Le volume de base est actuellement en cours de synchronisation. La création de l'image instantanée se termine dès que l'opération de synchronisation est terminée.
