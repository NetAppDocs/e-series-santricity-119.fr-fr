= Supprimer une image de snapshot dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous supprimez les images instantanées pour nettoyer l'image instantanée la plus ancienne d'un groupe d'instantanés ou d'un groupe de cohérence de snapshots.

.À propos de cette tâche
Vous pouvez supprimer une image instantanée individuelle ou supprimer des images instantanées de groupes de cohérence d'instantanés ayant le même horodatage de création. Vous pouvez également supprimer des images instantanées d'un groupe d'instantanés.

Vous ne pouvez pas supprimer une image instantanée si elle n'est pas l'image instantanée la plus ancienne du volume de base associé ou du groupe de cohérence de l'instantané.

.Étapes
. Sélectionnez le menu : Storage[Snapshots].
. Cliquez sur l’onglet *Snapshot Images*.
. Sélectionnez l'image snapshot que vous souhaitez supprimer et confirmez que vous souhaitez effectuer l'opération.
+
Si vous avez sélectionné une image instantanée d'un groupe de cohérence, sélectionnez chaque volume membre que vous souhaitez supprimer et confirmez que vous souhaitez effectuer l'opération.

. Cliquez sur *Delete*.


.Résultats
System Manager effectue les actions suivantes :

* Supprime l'image instantanée de la baie de stockage.
* Libère la capacité réservée pour une réutilisation au sein du groupe d'instantanés ou du groupe de cohérence d'instantanés.
* Désactive tous les volumes d'instantanés associés qui existent pour l'image d'instantané supprimée.
* À partir d'une suppression de groupe de cohérence d'instantané, tout volume membre associé à l'image d'instantané supprimée est déplacé vers un état Arrêté.
