[role="lead"]
La fonction Snapshot vous permet de créer des images à un instant précis des volumes de la storage array à utiliser pour la sauvegarde ou les tests.



[[what-are-snapshot-images]]
== Que sont les images instantanées ?

Une _image instantanée_ est une copie logique des données de volume, capturée à un moment précis. Comme un point de restauration, les images instantanées vous permettent de revenir à un jeu de données correct connu. Bien que l'hôte puisse accéder à l'image instantanée, il ne peut pas directement lire ou écrire dessus.

== Comment créer des instantanés ?
