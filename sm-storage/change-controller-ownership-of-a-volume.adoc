= Modifier la propriété du contrôleur d'un volume dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier le contrôleur propriétaire préféré d'un volume afin que les E/S des applications hôtes soient dirigées vers le nouveau chemin.

.Avant de commencer
Si vous n'utilisez pas de pilote multipath, toutes les applications hôtes utilisant actuellement le volume doivent être arrêtées. Cette mesure permet d'éviter les erreurs d'application lors d'un changement de chemin d'E/S.

.À propos de cette tâche
Vous pouvez modifier la propriété du contrôleur pour un ou plusieurs volumes dans un pool ou un groupe de volumes.

.Étapes
. Sélectionnez le menu : Storage[Volumes].
. Sélectionnez un volume quelconque, puis sélectionnez menu: More[Change ownership].
+
La boîte de dialogue « Modifier le propriétaire du volume » s'affiche. Tous les volumes de la baie de stockage apparaissent dans cette boîte de dialogue.

. Utilisez la liste déroulante *Propriétaire préféré* pour modifier le contrôleur préféré pour chaque volume que vous souhaitez modifier, et confirmez que vous souhaitez effectuer l'opération.


.Résultats
* System Manager modifie la propriété du contrôleur du volume. Les E/S vers le volume sont désormais dirigées via ce chemin d'E/S.
* Le volume pourrait ne pas utiliser le nouveau chemin d'E/S tant que le pilote multipath ne se reconfigure pas pour reconnaître le nouveau chemin. Cette opération prend généralement moins de cinq minutes.
