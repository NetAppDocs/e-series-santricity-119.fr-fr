= Surveillez les volumes fins dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez surveiller les volumes minces pour l'espace et générer des alertes appropriées, afin de prévenir les situations de manque de capacité.

[NOTE]
====
Cette fonctionnalité n'est pas disponible sur le système de stockage EF600/EF600C ou EF300/EF300C.

====
[NOTE]
====
SANtricity System Manager ne propose pas d'option pour créer des volumes fins. Si vous souhaitez créer des volumes fins, utilisez la Command Line Interface (CLI).

====
