= Initialiser les volumes dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Un volume est initialisé automatiquement lors de sa création. Cependant, le Recovery Guru peut vous conseiller d'initialiser manuellement un volume pour récupérer après certaines conditions de défaillance. N'utilisez cette option que sous la direction du support technique. Vous pouvez sélectionner un ou plusieurs volumes à initialiser.

.Avant de commencer
* Toutes les opérations d'E/S ont été arrêtées.
* Tous les périphériques ou systèmes de fichiers sur les volumes que vous souhaitez initialiser doivent être démontés.
* Le volume est dans un état optimal et aucune opération de modification n'est en cours sur le volume.


[CAUTION]
====
Vous ne pouvez pas annuler l'opération après son démarrage. Toutes les données du volume sont effacées. N'essayez pas cette opération à moins que le Recovery Guru ne vous le conseille. Contactez l'assistance technique avant de commencer cette procédure.

====
.À propos de cette tâche
Lors de l'initialisation d'un volume, celui-ci conserve son WWN, ses affectations d'hôtes, sa capacité allouée et sa capacité réservée. Il conserve également les mêmes paramètres Data Assurance (DA) et de sécurité.

Les types de volumes suivants _ne peuvent pas_ être initialisés :

* Volume de base d'un volume instantané
* Volume primaire dans une relation miroir
* Volume secondaire dans une relation miroir
* Volume source dans une copie de volume
* Volume cible dans une copie de volume
* Volume dont l'initialisation est déjà en cours


Ce sujet s'applique uniquement aux volumes standard créés à partir de pools ou de groupes de volumes.

.Étapes
. Sélectionnez le menu : Storage[Volumes].
. Sélectionnez un volume quelconque, puis sélectionnez menu: More[Initialize volumes].
+
La boîte de dialogue Initialiser les volumes s'affiche. Tous les volumes de la baie de stockage apparaissent dans cette boîte de dialogue.

. Sélectionnez un ou plusieurs volumes que vous souhaitez initialiser et confirmez que vous souhaitez effectuer l'opération.


.Résultats
System Manager effectue les actions suivantes :

* Efface toutes les données des volumes qui ont été initialisés.
* Efface les index de blocs, ce qui fait que les blocs non écrits sont lus comme s'ils étaient remplis de zéros (le volume apparaît comme complètement vide).


Sélectionnez menu:Home[View Operations in Progress] pour consulter la progression de l’opération d’initialisation en cours sur le volume sélectionné. Cette opération peut être longue et pourrait affecter les performances du système.
