= Exigences et directives relatives aux instantanés dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Lors de la création et de l'utilisation d'instantanés, examinez les exigences et les consignes suivantes.



[[snapshot-images-and-snapshot-groups]]
== Images instantanées et groupes d’instantanés

* Chaque image instantanée est associée à exactement un groupe d'instantanés.
* Un groupe d'instantanés est créé la première fois que vous créez une image d'instantané planifiée ou instantanée pour un objet associé. Cela crée une capacité réservée.
+
Vous pouvez consulter les groupes d'instantanés depuis la page Pools & Volume Groups.

* Les images instantanées planifiées ne sont pas effectuées lorsque la baie de stockage est hors ligne ou éteinte.
* Si vous supprimez un groupe d'instantanés qui possède une planification d'instantanés, la planification d'instantanés est également supprimée.
* Si vous possédez un volume de snapshot dont vous n'avez plus besoin, vous pouvez le réutiliser, ainsi que toute capacité réservée associée, au lieu de le supprimer. Cela crée un autre volume de snapshot du même volume de base. Vous pouvez réassocier le volume de snapshot ou le volume de snapshot d'un groupe de cohérence de snapshots à la même image de snapshot ou à une image de snapshot différente, à condition que l'image de snapshot se trouve dans le même volume de base.




[[snapshot-consistency-group]]
== groupe de cohérence de snapshot

* Un groupe de cohérence d’instantanés contient un groupe d’instantanés pour chaque volume qui est membre du groupe de cohérence d’instantanés.
* Vous pouvez associer un groupe de cohérence de snapshot à une seule planification.
* Si vous supprimez un groupe de cohérence d'instantané qui possède une planification d'instantané, la planification d'instantané est également supprimée.
* Vous ne pouvez pas gérer individuellement un groupe d'instantanés associé à un groupe de cohérence d'instantanés. Au lieu de cela, vous devez effectuer les opérations de gestion (créer une image d'instantané, supprimer une image d'instantané ou un groupe d'instantanés, et restaurer une image d'instantané) au niveau du groupe de cohérence d'instantanés.




[[base-volume]]
== Volume de base

* Un volume de snapshot doit avoir les mêmes paramètres d'assurance des données (DA) et de sécurité que le volume de base associé.
* Vous ne pouvez pas créer un volume instantané d'un volume de base défaillant.
* Si le volume de base se trouve sur un groupe de volumes, les volumes membres de tout groupe de cohérence de snapshot associé peuvent se trouver sur un pool ou un groupe de volumes.
* Si un volume de base réside sur un pool, tous les volumes membres de tout groupe de cohérence de snapshot associé doivent résider sur le même pool que le volume de base.




[[reserved-capacity]]
== Capacité réservée

* La capacité réservée est associée à un seul volume de base.
* L'utilisation d'une planification peut générer un grand nombre d'images instantanées. Assurez-vous de disposer d'une capacité réservée suffisante pour les instantanés planifiés.
* Le volume de capacité réservé pour un groupe de cohérence d'instantané doit avoir les mêmes paramètres d'assurance des données (DA) et de sécurité que son volume de base associé pour le volume membre du groupe de cohérence d'instantané.




[[pending-snapshot-images]]
== Images instantanées en attente

La création de l'image instantanée peut rester en attente dans les conditions suivantes :

* Le volume de base qui contient cette image instantanée est membre d'un groupe miroir asynchrone.
* Le volume de base est actuellement en cours de synchronisation. La création de l'image instantanée se termine dès que l'opération de synchronisation est terminée.




[[maximum-number-of-snapshot-images]]
== Nombre maximal d'images instantanées

* Si un volume est membre d'un groupe de cohérence de snapshots, System Manager crée un groupe d'instantanés pour ce volume membre. Ce groupe d'instantanés est comptabilisé dans le nombre maximal autorisé de groupes d'instantanés par volume de base.
* Si vous tentez de créer une image instantanée sur un groupe d'instantanés ou un groupe de cohérence d'instantanés, mais que le groupe associé a atteint son nombre maximal d'images instantanées, vous avez deux options :
+
** Activer la suppression automatique pour le groupe d'instantanés ou le groupe de cohérence d'instantanés.
** Supprimez manuellement une ou plusieurs images instantanées du groupe d'instantanés ou du groupe de cohérence d'instantanés, puis réessayez l'opération.






[[auto-deletion]]
== Suppression automatique

Si le groupe d'instantanés ou le groupe de cohérence est activé pour la suppression automatique, System Manager supprime l'image d'instantané la plus ancienne lorsque le système en crée une nouvelle pour le groupe.



[[rollback-operation]]
== Opération de restauration

* Vous ne pouvez pas effectuer les actions suivantes lorsqu'une opération de restauration est en cours :
+
** Supprimez l'image instantanée utilisée pour le rollback.
** Créez une nouvelle image instantanée pour un volume de base participant à une opération de restauration.
** Modifiez la stratégie Repository-Full du groupe d'instantanés associé.


* Vous ne pouvez pas lancer une opération de restauration lorsqu'une de ces opérations est en cours :
+
** Extension de capacité (ajout de capacité à un pool ou à un groupe de volumes)
** Extension de volume (augmentation de la capacité d'un volume)
** Modification du niveau RAID pour un groupe de volumes
** Changement de taille de segment pour un volume


* Vous ne pouvez pas lancer une opération de restauration si le volume de base participe à une copie de volume.
* Vous ne pouvez pas lancer une opération de restauration si le volume de base est un volume secondaire dans un miroir distant.
* Une opération de restauration échoue si une partie de la capacité utilisée dans le volume du référentiel de snapshots associé comporte des secteurs illisibles.
