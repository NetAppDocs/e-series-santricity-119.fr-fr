= Afficher les statistiques du cache SSD dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez consulter les statistiques du cache SSD, telles que les lectures, les écritures, les accès au cache, le pourcentage d'allocation du cache et le pourcentage d'utilisation du cache.

Les statistiques nominales, qui constituent un sous-ensemble des statistiques détaillées, sont affichées dans la boîte de dialogue « Afficher les statistiques du cache SSD ». Vous pouvez consulter les statistiques détaillées du cache SSD uniquement lorsque vous exportez toutes les statistiques SSD vers un fichier  `.csv`.

Lorsque vous examinez et interprétez les statistiques, gardez à l'esprit que certaines interprétations sont dérivées en examinant une combinaison de statistiques.

.Étapes
. Sélectionnez le menu : Storage [Pools & Volume Groups].
. Sélectionnez le cache SSD pour lequel vous souhaitez afficher les statistiques, puis cliquez sur menu:More[View SSD Cache statistics].
+
La boîte de dialogue « Afficher les statistiques du cache SSD » s’affiche et présente les statistiques nominales pour le cache SSD sélectionné.

+
.Détails du champ
[%collapsible]
====
[cols="25h,~"]
|===
| Paramètres | Description 


 a| 
Lectures
 a| 
Affiche le nombre total de lectures de l'hôte à partir des volumes activés pour le cache SSD. Plus le ratio de lectures par rapport aux écritures est élevé, meilleur est le fonctionnement du cache.



 a| 
Écritures
 a| 
Le nombre total d'écritures de l'hôte sur les volumes avec cache SSD activé. Plus le ratio de lectures par rapport aux écritures est élevé, meilleur est le fonctionnement du cache.



 a| 
Accès au cache
 a| 
Affiche le nombre d'accès au cache.



 a| 
Accès au cache %
 a| 
Affiche le pourcentage d'accès au cache. Ce chiffre est dérivé de Cache Hits / (lectures + écritures). Le pourcentage d'accès au cache doit être supérieur à 50 % pour un fonctionnement efficace du cache SSD.



 a| 
Cache allocation %
 a| 
Affiche le pourcentage de stockage du cache SSD qui est alloué, exprimé en pourcentage du stockage du cache SSD disponible pour ce contrôleur et dérivé des octets alloués / octets disponibles.



 a| 
Utilisation du cache %
 a| 
Affiche le pourcentage du stockage du cache SSD contenant des données provenant de volumes activés, exprimé en pourcentage du stockage du cache SSD alloué. Cette quantité représente l'utilisation ou la densité du cache SSD. Dérivé de octets alloués / octets disponibles.



 a| 
Exporter tout
 a| 
Exporte toutes les statistiques du cache SSD au format CSV. Le fichier exporté contient toutes les statistiques disponibles pour le cache SSD (à la fois nominales et détaillées).

|===
====
. Cliquez sur *Annuler* pour fermer la boîte de dialogue.
