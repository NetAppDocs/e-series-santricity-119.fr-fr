= Gérer la protection par mot de passe dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous devez configurer la baie de stockage avec des mots de passe pour la protéger contre tout accès non autorisé.



== Définir et modifier les mots de passe

Lors du premier démarrage de System Manager, vous êtes invité à définir un mot de passe administrateur. Tout utilisateur disposant du mot de passe administrateur peut apporter des modifications à la configuration de la baie de stockage, telles qu’ajouter, modifier ou supprimer des objets ou des paramètres. Pour définir le mot de passe administrateur lors du démarrage initial, consultez link:../san-getstarted/access-sam.html["Accéder à System Manager"].

Pour des raisons de sécurité, vous ne pouvez tenter de saisir un mot de passe que cinq fois avant que la baie de stockage n'entre dans un état de « lockout ». Dans cet état, la baie de stockage rejettera les tentatives de saisie de mot de passe suivantes. Vous devez attendre 10 minutes pour que la baie de stockage revienne à un état « normal » avant d'essayer de saisir à nouveau un mot de passe.

Outre le mot de passe administrateur, la baie de stockage inclut des profils utilisateur prédéfinis auxquels un ou plusieurs rôles sont associés. Pour plus d'informations, voir link:../sm-settings/permissions-for-mapped-roles.html["Autorisations pour les rôles mappés"]. Les profils utilisateur et les associations ne peuvent pas être modifiés. Seuls les mots de passe peuvent être modifiés. Si vous souhaitez modifier le mot de passe administrateur ou d'autres mots de passe utilisateur, voir link:../sm-settings/change-passwords.html["Changer les mots de passe"].



== Saisir à nouveau les mots de passe après l'expiration de la session

Le système vous demande le mot de passe une seule fois au cours d'une session de gestion. Cependant, une session expire après 30 minutes d'inactivité, moment auquel vous devez saisir à nouveau le mot de passe. Si un autre utilisateur gérant la même baie de stockage depuis un autre client de gestion modifie le mot de passe pendant que votre session est en cours, il vous sera demandé de saisir le mot de passe la prochaine fois que vous tenterez une opération de configuration ou d'affichage.

Vous pouvez ajuster le délai d'expiration de session ou désactiver complètement les délais d'expiration de session. Voir link:../sm-settings/manage-session-timeouts-sam.html["Gérer les délais d'expiration de session"].



== Supprimer les lecteurs ou la protection par mot de passe

Si vous retirez des disques protégés par mot de passe ou si vous souhaitez désactiver la protection par mot de passe, tenez compte des éléments suivants :

* *Si vous retirez des disques avec protection par mot de passe* -- Le mot de passe est stocké dans une zone réservée de chaque disque de la baie de stockage. Si vous retirez tous les disques d'une baie de stockage, son mot de passe ne fonctionnera plus. Pour corriger cette situation, réinstallez l'un des disques d'origine dans la baie de stockage.
* *Si vous souhaitez supprimer la protection par mot de passe* -- Si vous ne souhaitez plus que les commandes soient protégées par un mot de passe, saisissez le mot de passe administrateur actuel et laissez les nouvelles zones de texte du mot de passe vides.


[CAUTION]
====
L'exécution de commandes de configuration sur une baie de stockage peut entraîner des dommages importants, notamment une perte de données. Pour cette raison, vous devez toujours définir un mot de passe administrateur pour votre baie de stockage. Utilisez un mot de passe administrateur long d'au moins 15 caractères alphanumériques pour augmenter la sécurité.
