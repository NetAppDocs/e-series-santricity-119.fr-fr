= Découvrez la page des opérations en cours du gestionnaire de système SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La page « Opérations en cours » vous permet de consulter la liste des opérations de longue durée qui sont actuellement en cours d'exécution ou qui sont dans un état suspendu, arrêté ou ayant échoué. Vous pouvez effectuer une action sur certains types d'opérations.

Les opérations de longue durée peuvent affecter les performances du système. Pour certaines opérations, vous avez la possibilité d'arrêter l'opération ou de modifier sa priorité afin que les opérations plus importantes s'exécutent en premier.
