= Définissez la période par défaut pour les graphiques de performance dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez modifier la période par défaut affichée par les graphiques de performance.

.À propos de cette tâche
Les graphiques de performance affichés sur la page d'accueil et sur la page Performances indiquent initialement une période d'une heure. Les préférences sont enregistrées dans le stockage local du navigateur afin que chaque utilisateur puisse avoir ses propres paramètres.

.Étapes
. Sélectionnez menu : Preferences [Set preferences].
. Dans la liste déroulante, sélectionnez soit *5 minutes*, *1 heure*, *8 heures*, *1 jour* ou *7 jours*, et confirmez que vous souhaitez effectuer l'opération.
