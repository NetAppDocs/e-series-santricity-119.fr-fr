= Définir les unités par défaut pour les valeurs de capacité dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager peut afficher les valeurs de capacité en gibioctets (GiB) ou en tébioctets (TiB).

Les préférences sont stockées dans la mémoire locale du navigateur afin que chaque utilisateur puisse avoir ses propres paramètres.

.Étapes
. Sélectionnez menu : Preferences [Set preferences].
. Cliquez sur le bouton radio pour *Gibioctets* ou *Tébioctets*, et confirmez que vous souhaitez effectuer l'opération.
+
Voir le tableau suivant pour les abréviations et les valeurs.

+
[cols="1a,1a"]
|===
| Abréviation | Valeur 


 a| 
Gio
 a| 
1,024^3^ octets



 a| 
Tio
 a| 
1,024^4^ octets

|===
