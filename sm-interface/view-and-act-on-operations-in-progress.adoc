= Afficher et agir sur les opérations en cours dans SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour consulter et prendre des mesures concernant les opérations de longue durée, utilisez la page Operations in Progress.

.À propos de cette tâche
Pour chaque opération listée sur la page « Opérations en cours », un pourcentage d'achèvement et le temps restant estimé pour terminer l'opération sont affichés. Dans certains cas, vous pouvez arrêter une opération ou la placer à une priorité supérieure ou inférieure. Vous pouvez également effacer une opération de copie de volume terminée de la liste.

.Étapes
. Sur la page d'accueil, sélectionnez *Afficher les opérations en cours*.
+
La page Operations in Progress s'affiche.

. Si vous le souhaitez, utilisez les liens de la colonne Actions pour arrêter ou changer la priorité d'une opération.
+
[CAUTION]
====
Lisez tous les textes d'avertissement fournis dans les boîtes de dialogue, en particulier lors de l'arrêt d'une opération.

====
+
Vous pouvez interrompre une opération de copie de volume ou modifier sa priorité.

. Une fois l'opération de copie de volume terminée, vous pouvez sélectionner *Effacer* pour la supprimer de la liste.
+
En haut de la page d'accueil, un message d'information et une icône de clé jaune s'affichent une fois l'opération terminée. Ce message inclut un lien qui vous permet de supprimer l'opération depuis la page Opérations en cours.
