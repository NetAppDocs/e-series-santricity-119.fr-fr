= Supprimer un groupe de cohérence miroir dans SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez supprimer les groupes de cohérence miroir qui ne sont plus nécessaires sur la matrice de stockage locale et sur la matrice de stockage distante.

.Avant de commencer
Toutes les paires symétriques doivent être retirées du groupe de cohérence de miroir.

.Étapes
. Sélectionnez menu : Storage[Asynchronous Mirroring].
. Sélectionnez l’onglet *Mirror Consistency Groups*.
+
Le tableau Mirror Consistency Group s'affiche et présente tous les mirror consistency groups associés à la baie de stockage.

. Sélectionnez le groupe de cohérence miroir que vous souhaitez supprimer, puis sélectionnez menu:Uncommon Tasks[Delete].
+
Le système affiche une confirmation.

. Sélectionnez *Oui* pour supprimer le groupe de cohérence du miroir.


.Résultats
System Manager effectue les actions suivantes :

* Supprime d'abord le groupe de cohérence miroir sur la baie de stockage locale, puis supprime le groupe de cohérence miroir sur la baie de stockage distante.
* Supprime le groupe de cohérence miroir du tableau Mirror Consistency Group.


.Après avoir terminé
Il peut arriver que le groupe de cohérence miroir soit supprimé avec succès de la baie de stockage locale, mais qu'une erreur de communication empêche la suppression du groupe de cohérence miroir de la baie de stockage distante. Dans ce cas, vous devez accéder à la baie de stockage distante pour supprimer le groupe de cohérence miroir correspondant.
