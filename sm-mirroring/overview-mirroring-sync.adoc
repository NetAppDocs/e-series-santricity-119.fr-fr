= Découvrez la mise en miroir synchrone dans le logiciel SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La fonction de mise en miroir synchrone assure la réplication des données en ligne et en temps réel entre les baies de stockage sur une distance distante.

[NOTE]
====
Cette fonctionnalité n'est pas disponible sur le système de stockage EF600/EF600C ou EF300/EF300C.

====


[[what-is-synchronous-mirroring]]
== Qu'est-ce que la mise en miroir synchrone ?

La mise en miroir synchrone réplique les volumes de données en temps réel pour garantir une disponibilité continue. Les contrôleurs de baies de stockage gèrent l'opération de mise en miroir, qui est transparente pour les machines hôtes et les applications logicielles.

Ce type de mise en miroir est idéal pour des besoins de continuité des activités tels que la reprise après sinistre.

[[how-do-i-configure-synchronous-mirroring]]
== Comment configurer la mise en miroir synchrone ?

Vous devez utiliser l'interface Unified Manager pour effectuer la configuration initiale de la mise en miroir entre les baies. Une fois celle-ci configurée, vous pouvez gérer les paires mises en miroir dans System Manager.
