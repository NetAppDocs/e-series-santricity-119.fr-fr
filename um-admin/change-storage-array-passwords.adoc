= Modifier les mots de passe des baies de stockage dans SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez mettre à jour les mots de passe utilisés pour afficher et accéder aux baies de stockage dans SANtricity Unified Manager.

.Avant de commencer
* Vous devez être connecté avec un profil utilisateur qui inclut les autorisations d'administrateur de stockage.
* Vous devez connaître le mot de passe actuel de la baie de stockage, qui est défini dans System Manager.


.À propos de cette tâche
Dans cette tâche, vous saisissez le mot de passe actuel d'une baie de stockage afin d'y accéder dans Unified Manager. Cette opération peut s'avérer nécessaire si le mot de passe de la baie a été modifié dans System Manager et doit également l'être dans Unified Manager.

.Étapes
. Sur la page Gérer, sélectionnez une ou plusieurs baies de stockage.
. Sélectionnez le menu : Uncommon Tasks [Provide Storage Array Passwords].
. Saisissez le mot de passe ou les mots de passe de chaque baie de stockage, puis cliquez sur *Enregistrer*.
