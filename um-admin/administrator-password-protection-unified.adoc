= Découvrez la protection par mot de passe administrateur dans SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous devez configurer SANtricity Unified Manager avec un mot de passe administrateur pour le protéger contre tout accès non autorisé.



== Mot de passe administrateur et profils d'utilisateurs

Lors du premier lancement d'Unified Manager, vous êtes invité à définir un mot de passe administrateur. Tout utilisateur qui possède le mot de passe administrateur peut apporter des modifications à la configuration des baies de stockage.

Outre le mot de passe administrateur, l'interface Unified Manager comprend des profils utilisateur préconfigurés auxquels sont associés un ou plusieurs rôles. Pour plus d'informations, voir link:../um-certificates/how-access-management-works-unified.html["Comment fonctionne la gestion des accès"].

Les utilisateurs et les correspondances ne peuvent pas être modifiés. Seuls les mots de passe peuvent être modifiés. Pour modifier les mots de passe, consultez :

* link:change-admin-password-unified.html["Modifier le mot de passe admin"]
* link:../um-certificates/change-passwords-unified.html["Modifier les mots de passe des profils d'utilisateurs locaux"]




== Expiration de la session

Le logiciel vous demande le mot de passe une seule fois au cours d'une session de gestion. Une session expire après 30 minutes d'inactivité par défaut, moment auquel vous devez saisir à nouveau le mot de passe. Si un autre utilisateur accède au logiciel depuis un autre client de gestion et modifie le mot de passe pendant que votre session est en cours, il vous sera demandé de saisir le mot de passe la prochaine fois que vous tenterez une opération de configuration ou d'affichage.

Pour des raisons de sécurité, vous ne pouvez tenter de saisir un mot de passe que cinq fois avant que le logiciel ne passe à l'état de « lockout ». Dans cet état, le logiciel rejette les tentatives de saisie de mot de passe suivantes. Vous devez attendre 10 minutes pour réinitialiser à l'état « normal » avant d'essayer de saisir à nouveau un mot de passe.

Vous pouvez ajuster les délais d'expiration de session ou vous pouvez désactiver complètement les délais d'expiration de session. Pour plus d'informations, voir link:manage-session-timeouts-unified.html["Gérer les délais d'expiration de session"].
