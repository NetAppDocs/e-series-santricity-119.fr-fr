= Supprimer des baies de stockage d'un groupe dans SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez supprimer une ou plusieurs baies de stockage gérées d'un groupe si vous ne souhaitez plus les gérer à partir d'un groupe de stockage spécifique.

.À propos de cette tâche
Le retrait d'une baie de stockage d'un groupe n'affecte en rien la baie de stockage ni ses données. Si votre baie de stockage est gérée par System Manager, vous pouvez toujours la gérer à l'aide de votre navigateur. Si une baie de stockage est retirée accidentellement d'un groupe, elle peut être ajoutée de nouveau.

.Étapes
. Depuis la page Manage, sélectionnez menu : Manage Groups[Remove storage arrays from group].
. Dans la liste déroulante, sélectionnez le groupe qui contient les baies de stockage que vous souhaitez supprimer, puis cliquez sur la case à cocher à côté de chaque baie de stockage que vous souhaitez supprimer du groupe.
. Cliquez sur *Remove*.
