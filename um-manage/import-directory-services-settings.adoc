= Importer les paramètres des services d'annuaire dans SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez importer une configuration des services d'annuaire d'une baie de stockage vers d'autres baies de stockage. Cette opération par lots permet de gagner du temps lorsque vous devez configurer plusieurs baies dans le réseau.

.Avant de commencer
* Les services d'annuaire sont configurés dans System Manager pour la baie de stockage que vous souhaitez utiliser comme source (menu:Settings[Access Management]).
* La configuration existante des baies de stockage cibles est sauvegardée dans System Manager (menu: Paramètres [Système > Enregistrer la configuration de la baie de stockage]).


.À propos de cette tâche
Les paramètres importés comprennent le nom de domaine et l'URL d'un serveur LDAP (Lightweight Directory Access Protocol), ainsi que les correspondances entre les groupes d'utilisateurs du serveur LDAP et les rôles prédéfinis de la baie de stockage.

.Étapes
. Depuis la page Manage, cliquez sur *Import Settings*.
+
L'assistant d'importation des paramètres s'ouvre.

. Dans la boîte de dialogue Select Settings, sélectionnez *Directory services* puis cliquez sur *Next*.
+
Une boîte de dialogue s'ouvre pour sélectionner le tableau source.

. Dans la boîte de dialogue Select Source, sélectionnez l'array avec les paramètres que vous souhaitez importer, puis cliquez sur *Next*.
. Dans la boîte de dialogue Select Targets, sélectionnez un ou plusieurs arrays pour recevoir les nouveaux paramètres.
+
[NOTE]
====
Les baies de stockage dont le firmware est inférieur à 8.50 ne sont pas disponibles pour la sélection. De plus, une baie n'apparaît pas dans cette boîte de dialogue si Unified Manager ne peut pas communiquer avec cette baie (par exemple, si elle est hors ligne ou si elle présente des problèmes de certificat, de mot de passe ou de réseau).

====
. Cliquez sur *Terminer*.
+
La page Opérations affiche les résultats de l'opération d'importation. Si l'opération échoue, vous pouvez cliquer sur sa ligne pour voir plus d'informations.





== Résultats

Les baies de stockage cibles sont désormais configurées avec les mêmes services d'annuaire que la baie source.
