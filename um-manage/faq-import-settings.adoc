[[what-settings-will-be-imported]]
== Quels paramètres seront importés ?

La fonction Import Settings est une opération par lots qui charge les configurations d'une baie de stockage vers plusieurs baies de stockage. Les paramètres importés lors de cette opération dépendent de la façon dont la baie de stockage source est configurée dans SANtricity System Manager.

Les paramètres suivants peuvent être importés dans plusieurs baies de stockage :

* *Alertes par e-mail* -- Les paramètres incluent une adresse de serveur de messagerie et les adresses e-mail des destinataires des alertes.
* *Alertes Syslog* -- Les paramètres incluent une adresse de serveur syslog et un port UDP.
* *Alertes SNMP* -- Les paramètres incluent un nom de communauté et une adresse IP pour le serveur SNMP.
* *AutoSupport* -- Les paramètres comprennent les fonctionnalités distinctes (Basique AutoSupport, AutoSupport OnDemand et Diagnostics à distance), la fenêtre de maintenance, la méthode de livraison et le calendrier d'expédition.
* *Services d'annuaire* -- La configuration comprend le nom de domaine et l'URL d'un serveur LDAP (Lightweight Directory Access Protocol), ainsi que les correspondances entre les groupes d'utilisateurs du serveur LDAP et les rôles prédéfinis de la baie de stockage.
* *Configuration du stockage* -- Les configurations comprennent les volumes (uniquement épais et uniquement non-référentiels), les groupes de volumes, les pools et les affectations de disques de secours à chaud.
* *Paramètres système* -- Les configurations comprennent les paramètres d'analyse des supports pour un volume, le cache SSD pour les contrôleurs et l'équilibrage de charge automatique (n'inclut pas la connectivité hôte).




[[why-dont-i-see-all-of-my-storage-arrays]]
== Pourquoi ne vois-je pas toutes mes baies de stockage ?

Lors de l'opération Import Settings, certaines de vos baies de stockage peuvent ne pas être disponibles dans la boîte de dialogue de sélection de la cible.

Les baies de stockage peuvent ne pas apparaître pour les raisons suivantes :

* La version du firmware est inférieure à 8.50.
* La baie de stockage est hors ligne.
* Le système ne peut pas communiquer avec cette baie (par exemple, la baie a des problèmes de certificat, de mot de passe ou de réseau).
