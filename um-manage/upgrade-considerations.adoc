= Découvrez comment mettre à niveau plusieurs systèmes de stockage avec SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Avant d'utiliser SANtricity Unified Manager pour mettre à niveau plusieurs systèmes de stockage E-Series, examinez les principales considérations dans le cadre de votre planification.



== Versions actuelles

Vous pouvez consulter les versions actuelles du logiciel SANtricity OS depuis la page Gérer d'Unified Manager pour chaque baie de stockage détectée. La version est affichée dans la colonne Logiciel SANtricity OS. Les informations relatives au microprogramme du contrôleur et à la NVSRAM sont disponibles dans une boîte de dialogue contextuelle lorsque vous cliquez sur la version SANtricity OS dans chaque ligne.



== Autres composants nécessitant une mise à niveau

Dans le cadre du processus de mise à niveau, vous devrez peut-être également mettre à niveau le pilote multipath/basculement de l'hôte ou le pilote HBA afin que l'hôte puisse interagir correctement avec les contrôleurs.

Pour plus d'informations sur la compatibilité, consultez le  https://imt.netapp.com/matrix/#welcome["NetApp Matrice d'interopérabilité"^]. Consultez également les procédures dans les Express Guides pour votre système d'exploitation. Les Express Guides sont disponibles auprès du  https://docs.netapp.com/us-en/e-series/index.html["Documentation E-Series et SANtricity"^].



== Contrôleurs doubles

Si une baie de stockage contient deux contrôleurs et que vous avez installé un pilote multipath, la baie de stockage peut continuer à traiter les E/S pendant la mise à niveau. Pendant la mise à niveau, le processus suivant se produit :

. Le contrôleur A bascule tous ses LUN vers le contrôleur B.
. La mise à niveau s'effectue sur le contrôleur A.
. Le contrôleur A récupère ses LUN et toutes les LUN du contrôleur B.
. La mise à niveau s'effectue sur le contrôleur B.


Une fois la mise à niveau terminée, vous devrez peut-être redistribuer manuellement les volumes entre les contrôleurs pour garantir que les volumes retournent au contrôleur propriétaire approprié.
