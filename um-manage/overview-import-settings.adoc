= Découvrez l'importation des paramètres de baie de stockage dans SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La fonction Import Settings permet d'effectuer une opération par lots pour importer les paramètres d'une baie vers plusieurs baies. Cette fonction permet de gagner du temps lorsque vous devez configurer plusieurs baies dans le réseau.



[[what-settings-can-be-imported]]
== Quels paramètres peuvent être importés ?

Vous pouvez importer les méthodes d'alerte, les configurations AutoSupport, les configurations des services d'annuaire, les configurations de stockage (telles que les groupes de volumes et les pools) et les paramètres système (tels que l'équilibrage de charge automatique).

En savoir plus :

* link:how-import-settings-works.html["Comment fonctionne l'importation des paramètres"]
* link:requirements-for-replicating-storage-configurations.html["Exigences pour la réplication des configurations de stockage"]




[[how-do-i-perform-a-batch-import]]
== Comment effectuer une importation par lots ?

Sur une baie de stockage à utiliser comme source, ouvrez System Manager et configurez les paramètres souhaités. Ensuite, depuis Unified Manager, accédez à la page Manage et importez les paramètres vers une ou plusieurs baies.
