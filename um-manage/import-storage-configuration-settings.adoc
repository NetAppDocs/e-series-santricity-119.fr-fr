= Importer les paramètres de configuration du stockage dans SANtricity Unified Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez importer la configuration de stockage d'une baie de stockage vers d'autres baies de stockage. Cette opération par lots permet de gagner du temps lorsque vous devez configurer plusieurs baies de stockage sur le réseau.

.Avant de commencer
* Le stockage est configuré dans SANtricity System Manager pour la baie de stockage que vous souhaitez utiliser comme source.
* La configuration existante des baies de stockage cibles est sauvegardée dans System Manager (menu: Paramètres [Système > Enregistrer la configuration de la baie de stockage]).
* Les tableaux source et cible doivent répondre aux exigences suivantes :
+
** Les étagères où résident les contrôleurs doivent être identiques.
** Les identifiants d'étagère doivent être identiques.
** Les baies d'extension doivent être équipées dans les mêmes emplacements avec les mêmes types de disques.
** Le type de boîtier RBOD doit être identique.
** Les HIC, y compris les capacités Data Assurance de l'hôte, doivent être identiques.
** Les baies cibles doivent être dans un état optimal.
** La capacité du volume sur la baie cible est supérieure à la capacité de la baie source.


* Vous comprenez les restrictions suivantes :
+
** L'importation d'une configuration duplex vers une configuration simplex n'est pas prise en charge ; cependant, l'importation d'une configuration simplex vers une configuration duplex est autorisée.
** Les volumes du pool de disques de 64 To ou plus sur la baie source empêcheront le processus d'importation sur les cibles.
** Les volumes minces ne sont pas inclus dans le processus d'importation.




.À propos de cette tâche
Les paramètres importés comprennent les volumes configurés (volumes épais et non-référentiels uniquement), les groupes de volumes, les pools et les affectations de disques de secours à chaud.

.Étapes
. Depuis la page Manage, cliquez sur *Import Settings*.
+
L'assistant d'importation des paramètres s'ouvre.

. Dans la boîte de dialogue Sélectionner les paramètres, sélectionnez *Storage configuration* puis cliquez sur *Next*.
+
Une boîte de dialogue s'ouvre pour sélectionner le tableau source.

. Dans la boîte de dialogue Select Source, sélectionnez l'array avec les paramètres que vous souhaitez importer, puis cliquez sur *Next*.
. Dans la boîte de dialogue Select Targets, sélectionnez un ou plusieurs arrays pour recevoir les nouveaux paramètres.
+
[NOTE]
====
Les baies de stockage dont le firmware est inférieur à 8.50 ne sont pas disponibles pour la sélection. De plus, une baie n'apparaît pas dans cette boîte de dialogue si Unified Manager ne peut pas communiquer avec cette baie (par exemple, si elle est hors ligne ou si elle présente des problèmes de certificat, de mot de passe ou de réseau).

====
. Cliquez sur *Terminer*.
+
La page Opérations affiche les résultats de l'opération d'importation. Si l'opération échoue, vous pouvez cliquer sur sa ligne pour voir plus d'informations.



.Résultats
Les baies de stockage cibles sont maintenant configurées avec la même configuration de stockage que la baie source.
