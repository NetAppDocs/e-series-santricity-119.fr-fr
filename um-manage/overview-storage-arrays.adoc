= En savoir plus sur la découverte dans SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour gérer les ressources de stockage, vous devez d'abord découvrir les baies de stockage dans le réseau.



[[how-do-i-discover-arrays]]
== Comment puis-je découvrir les arrays ?

Utilisez la page Ajouter/Découvrir pour rechercher et ajouter les baies de stockage que vous souhaitez gérer sur le réseau de votre organisation. Vous pouvez détecter plusieurs baies ou vous pouvez détecter une seule baie. Pour ce faire, vous saisissez les adresses IP du réseau, puis Unified Manager tente des connexions individuelles à chaque adresse IP de cette plage.

En savoir plus :

* link:considerations-for-discovering-arrays.html["Considérations relatives à la découverte des tableaux"]
* link:discover-multiple-arrays.html["Découvrez plusieurs baies de stockage"]
* link:discover-single-array.html["Découvrir une seule baie"]




[[how-do-i-manage-arrays]]
== Comment gérer les arrays ?

Après avoir découvert les baies, accédez à la page *Manage - All*. Depuis cette page, vous pouvez faire défiler la liste des baies de stockage découvertes sur votre réseau, consulter leur état et effectuer des opérations sur une seule baie ou sur un groupe de baies.

Si vous souhaitez gérer un seul tableau, vous pouvez le sélectionner et ouvrir System Manager.

En savoir plus :

* link:launch-considerations.html["Considérations relatives à l'accès à System Manager"]
* link:launch-system-manager.html["Gérer une baie de stockage individuelle"]
* link:storage-array-status.html["Afficher l'état de la baie de stockage"]
