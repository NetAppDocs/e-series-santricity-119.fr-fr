= Gérer une baie de stockage individuelle dans SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser l'option Lancer pour ouvrir le SANtricity System Manager basé sur un navigateur pour une ou plusieurs baies de stockage lorsque vous souhaitez effectuer des opérations de gestion.

.Étapes
. Sur la page Manage, sélectionnez une ou plusieurs storage arrays que vous souhaitez gérer.
. Cliquez sur *Launch*.
+
Le système ouvre une nouvelle fenêtre et affiche la page de connexion System Manager.

. Saisissez votre nom d'utilisateur et votre mot de passe, puis cliquez sur *Se connecter*.
