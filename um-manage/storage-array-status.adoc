= Afficher l'état de la baie de stockage dans SANtricity Unified Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Manager affiche l'état de chaque système de stockage détecté.

Accédez à la page *Gérer - Tout*. Sur cette page, vous pouvez consulter l'état de la connexion entre le Web Services Proxy et ce système de stockage.

Les indicateurs d'état sont décrits dans le tableau suivant.

[cols="25h,~"]
|===
| Statut | Indique 


 a| 
Optimal
 a| 
La baie de stockage est dans un état optimal. Il n'y a aucun problème de certificat et le mot de passe est valide.



 a| 
Mot de passe invalide
 a| 
Un mot de passe de système de stockage non valide a été fourni.



 a| 
Certificat non approuvé
 a| 
Une ou plusieurs connexions avec la baie de stockage ne sont pas fiables car le certificat HTTPS est soit auto-signé et n'a pas été importé, soit signé par une autorité de certification et les certificats d'autorité de certification racine et intermédiaire n'ont pas été importés.



 a| 
Nécessite une attention
 a| 
Il y a un problème avec la baie de stockage qui nécessite votre intervention pour le corriger.



 a| 
Confinement
 a| 
La baie de stockage est dans un état verrouillé.



 a| 
Inconnu
 a| 
Le système de stockage n'a jamais été contacté. Cela peut se produire lorsque le proxy des services Web est en cours de démarrage et n'a pas encore établi de contact avec le système de stockage, ou lorsque le système de stockage est hors ligne et n'a jamais été contacté depuis le démarrage du proxy des services Web.



 a| 
Hors ligne
 a| 
Le proxy des services Web avait précédemment contacté la baie de stockage, mais a maintenant perdu toute connexion avec celle-ci.

|===
